# Rancangan Struktur Database (Skema Relasional)

Berikut adalah konsep struktur tabel database inti yang direkomendasikan (bisa diimplementasikan di PostgreSQL, MySQL, atau Firebase Firestore).

## 1. Tabel `users` (Pengguna)
* `id` (Primary Key, UUID)
* `nama_lengkap` (String)
* `no_hp` / `email` (String, Unique)
* `password_hash` (String)
* `role` (Enum: 'admin', 'penghuni', 'investor')
* `foto_profil` (String/URL)
* `kontak_darurat_nama` (String, opsional)
* `kontak_darurat_hp` (String, opsional)
* `created_at` (Timestamp)

## 2. Tabel `kos` (Properti Kos)
* `id` (Primary Key)
* `admin_id` (Foreign Key ke users.id)
* `nama_kos` (String)
* `alamat` (Text)
* `jumlah_kamar` (Integer)

## 3. Tabel `rooms` (Kamar)
* `id` (Primary Key)
* `kos_id` (Foreign Key ke kos.id)
* `nomor_kamar` (String, misal: "101", "102")
* `tipe_kamar` (String, misal: "AC + Kamar Mandi Dalam")
* `harga_sewa_dasar` (Decimal/Integer)
* `status` (Enum: 'Tersedia', 'Terisi', 'Perbaikan')

## 4. Tabel `contracts` (Sewa/Kontrak Penghuni)
* `id` (Primary Key)
* `penghuni_id` (Foreign Key ke users.id)
* `room_id` (Foreign Key ke rooms.id)
* `tanggal_masuk` (Date)
* `tanggal_keluar` (Date, bisa Null jika terus berlanjut)
* `deposit_awal` (Decimal)
* `denda_harian` (Decimal)
* `status_sewa` (Enum: 'Aktif', 'Selesai')

## 5. Tabel `invoices` (Tagihan & Pemasukan)
* `id` (Primary Key)
* `contract_id` (Foreign Key ke contracts.id)
* `bulan_tagihan` (Date/String, misal: "2026-10")
* `tanggal_jatuh_tempo` (Date)
* `nominal_kamar` (Decimal)
* `tambahan_listrik` (Decimal)
* `denda` (Decimal)
* `total_tagihan` (Decimal)
* `status_pembayaran` (Enum: 'Belum Bayar', 'Menunggu Verifikasi', 'Lunas')
* `metode_pembayaran` (String, misal: "BCA_VA", "QRIS") - *Baru*
* `kode_pembayaran` (String) - *Nomor Virtual Account atau link QRIS* - *Baru*
* `payment_gateway_ref` (String) - *ID Transaksi dari Midtrans/Xendit* - *Baru*
* `tanggal_bayar` (Timestamp)

## 6. Tabel `expenses` (Pengeluaran Operasional)
* `id` (Primary Key)
* `kos_id` (Foreign Key ke kos.id)
* `kategori` (Enum: 'Listrik', 'Air', 'Gaji', 'Perbaikan', 'Lainnya')
* `nominal` (Decimal)
* `deskripsi` (Text)
* `tanggal_pengeluaran` (Date)
* `bukti_struk` (String/URL)

## 7. Tabel `investors_shares` (Kepemilikan Saham Investor)
* `id` (Primary Key)
* `kos_id` (Foreign Key ke kos.id)
* `investor_id` (Foreign Key ke users.id)
* `persentase` (Decimal, misal: 30.00 untuk 30%)
* `status` (Enum: 'Aktif', 'Nonaktif')

## 8. Tabel `profit_sharing` (Rekap Bagi Hasil Bulanan)
* `id` (Primary Key)
* `kos_id` (Foreign Key ke kos.id)
* `periode_bulan` (String, misal: "2026-10")
* `total_pemasukan` (Decimal)
* `total_pengeluaran` (Decimal)
* `laba_bersih` (Decimal)

## 9. Tabel `profit_sharing_details` (Rincian Pencairan per Investor)
* `id` (Primary Key)
* `profit_sharing_id` (Foreign Key ke profit_sharing.id)
* `investor_id` (Foreign Key ke users.id)
* `nominal_bagian` (Decimal)
* `status_pencairan` (Enum: 'Menunggu', 'Ditransfer')
* `bukti_transfer_investor` (String/URL)

## 10. Tabel `complaints` (Komplain Penghuni)
* `id` (Primary Key)
* `penghuni_id` (Foreign Key ke users.id)
* `room_id` (Foreign Key ke rooms.id)
* `deskripsi_masalah` (Text)
* `foto_masalah` (String/URL)
* `status_komplain` (Enum: 'Menunggu', 'Diproses', 'Selesai')
* `created_at` (Timestamp)
